# Alfred Spotlight Theme

Temas para o [Alfred 5](https://www.alfredapp.com/) inspirados no Spotlight do macOS, com a barra "Busque ou pergunte" da Siri.

| Tema | Base |
| --- | --- |
| `Spotlight Golden Gate Dark` | macOS 27 Golden Gate, vidro escuro |
| `Spotlight Golden Gate Light` | macOS 27 Golden Gate, vidro claro |
| `Spotlight Tahoe Dark` | macOS 26 Tahoe, vidro escuro |
| `Spotlight Tahoe Light` | macOS 26 Tahoe, vidro claro |

## Instalação

1. Baixe o arquivo `.alfredappearance` do tema na pasta `themes/`.
2. Abra o arquivo com dois cliques. O Alfred pergunta se quer importar.
3. Escolha o tema em **Alfred Preferences → Appearance**.

Para a barra ficar parecida com a do Spotlight, esconda o chapéu do Alfred em **Appearance → Options**.

## Limitações

O formato de tema do Alfred só tem cor, fonte, tamanho, espaçamento e arredondamento. Não dá para reproduzir:

- as animações de abertura e o brilho da Siri;
- o placeholder "Busque ou pergunte" e o ícone de microfone;
- o gradiente do vidro (o Alfred só aceita cor sólida).
